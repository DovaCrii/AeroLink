# Inventario seguro de flota DJI

Usar una copia de esta plantilla por cada combinación de aeronave y control.
No guardar números de serie, credenciales, certificados, tokens ni capturas
operacionales en Git. El identificador de serial debe ser una referencia al
inventario interno o a una bóveda autorizada.

## Contexto

| Campo | Valor |
|---|---|
| Faena / workspace | Pendiente |
| Responsable del inventario | Pendiente |
| Fecha de verificación | YYYY-MM-DD |
| Identificador interno de activo | Ejemplo: `DRN-001` |
